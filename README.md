
# Spring Boot E-Commerce Backend

A backend e-commerce application developed using **Java and Spring Boot**, providing RESTful APIs for managing users, products, and orders.

##  Features

* User management
* Product management
* Order management
* Order item management
* RESTful APIs
* MySQL database integration
* Spring Data JPA and Hibernate
* DTO-based request handling
* Entity relationships using JPA
* Order total price calculation
* Exception handling
* Input validation

##  Technologies Used

* **Java**
* **Spring Boot**
* **Spring Data JPA**
* **Hibernate**
* **MySQL**
* **Maven**
* **REST APIs**
* **Lombok**
* **Eclipse / Spring Tools**


##  Database

The application uses **MySQL** as the relational database.

Main entities include:

* User
* Product
* Order
* OrderItem

The relationships between entities are managed using **JPA/Hibernate**.

## 🔗 API Modules

### User APIs

Used for creating, retrieving, updating, and managing users.

### Product APIs

Used for managing product information such as:

* Product name
* Description
* Brand
* Price
* Rating
* Available quantity

### Order APIs

Used for:

* Creating orders
* Retrieving orders
* Updating orders
* Managing order items
* Calculating order total price
